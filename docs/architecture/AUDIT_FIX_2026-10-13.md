# Nusa WMS audit and menu separation — 2026-10-13

## Changes
- `fast-slow-dead` now uses a dedicated handler and displays a configurable-in-code, clearly disclosed classification based on last ledger movement: Fast <= 30 days, Slow 31–90 days, Dead > 90 days or no ledger movement. Items with no on-hand stock are classified separately.
- Inventory and ledger aggregates are computed in separate subqueries to avoid multiplying quantities when products have many inventory rows and many ledger rows.
- `movement-tracking` now has its own handler with date range and SKU/product-name filters, capped at 1,000 newest rows.
- `master-produk-cloud` now explicitly reports that cloud integration is not configured and links to the local product master instead of presenting local CRUD as a cloud feature.
- Removed the duplicate `inbound` entry from the reference navigation group. The main logistics menu remains the canonical Inbound route.
- Added structural regression checks for the new handlers and the PDO prepared query used by scan sessions.
